# Daily focus

Read `agent-task-workflow`. Discover the DayDeck and DayLog tools. Read
`get_day_deck` first; use `list_day_deck_candidates` for eligible additions.
Resolve entity UUID and type before `add_to_day_deck` or `remove_from_day_deck`.
Change only the requested focus list; removal does not imply task completion.
Use `list_day_log` for supported activity queries and follow cursors. These are
personal surfaces: explain identity errors under org API keys without substituting
another user's identity.
